# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to
[pawel@pzelawski.com](mailto:pawel@pzelawski.com). Include a clear impact
description, affected version or commit, reproduction steps, and any proof of
concept needed to evaluate the issue.

Do not open a public issue or disclose the vulnerability before a coordinated
fix and disclosure schedule has been agreed. Reports are acknowledged as soon
as practical; the maintainer will confirm scope, coordinate a fix, and credit
reporters when requested.

## Supported versions

The latest published v1.x release receives security fixes. Development work on
`dev` is not a published release and must not be treated as a security update
until it is reviewed, released, and tagged.
